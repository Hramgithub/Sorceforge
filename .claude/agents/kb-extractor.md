Ты переносишь одну часть книги в базу знаний «Зов Ктулху» 7e (JSON в git, `C:\_Hobby\_work\Sorceforge`).

- Твоё задание — файл, путь к которому дан в промпте. Прочитай его целиком; в конце задания — правила
  записи `docs/conventions.md`, они важнее всего остального.
- Книгу читай инструментом страниц: `python pipeline/source/pages.py show|grep|image <book_id> …`.
  Числа и таблицы сверяй по изображению страницы, если текст сомнителен.
- Пиши только файлы, которые задание отдаёт твоей части. Правки чужих и общих записей — только в файл
  предложений (формат `pipeline/integrate/README.md`).
- Ничего не придумывай: каждое число и факт — со страницы книги; вывод из текста помечай.
  Ничего не выбрасывай молча: не взятое — в «Не взято» с причиной.
- Свои файлы проверяй: `python tools/check.py <файлы>` — ошибок 0.
- Не запускай git вообще, даже `git status`: свои изменённые файлы видно через `python tools/check.py --changed`.
  Не собирай просмотрщик, не запускай `pipeline/fix/*` без списка файлов.
- Python — `python -I`; скрипты пиши в `.py` файлы в своей временной папке, не в `python -c`.
- В конце — короткий отчёт по разделу «Report» задания.

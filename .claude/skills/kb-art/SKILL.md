# Картинки записей

Поле `images[]` записи: `{file, kind, caption, source, section?, table?}` (`schemas/common.schema.json`,
`docs/conventions.md`). Копии — `app/art/<kind>s/<slug>[-n].webp` (≤1400 px, WebP 80); оригиналы остаются на месте.

## 1. Где искать

- Веб-помощник `C:\_Hobby\_work\git_coc\web_helper_coc_gm\public\docs`: арт существ, фото оружия (данные с
  лицензиями — `weapons/data/weapons_for_site.json`).
- Картотека владельца `3_КБ` (раздатка, карточки) и `1_Библиотека` (папки «Прегены», PDF книг) — Р-164.
- Сопоставление с записями — по имени и «также» (`name.ru`, `name.en`, `aliases`) или по странице источника
  записи (`sources[].physical_page`). Неоднозначное — не угадывать, показать владельцу.

## 2. Как достать из PDF (Poppler)

- `pdfimages -list` — картинки по страницам. Портрет на листе персонажа — картинка, чей объект встречается
  только на этой странице (фон и рамки повторяются на всех листах); мелочь < 90–120 px отбросить.
- `pdfimages -f N -l N -png` — извлечь; CMYK переводится сам; маска (`smask`) — альфа-канал.
- Несколько записей на странице (колоды карточек): порядок картинок в PDF меняется от страницы к странице —
  положение брать из `pdftohtml -xml` (у картинок и текста есть `top`), картинку отдавать записи, чьё имя в той
  же половине страницы.
- Фото, разрезанное на куски, и сканы-фотоснимки страниц: `pdftoppm -r 150…216` и вырезка по рамке; рамки
  (доли страницы) сохранить в `checks/…/*-boxes.json`, чтобы вырезку можно было повторить.
- Файлы Яндекс.Диска читаются долго — извлечение запускать в фоне.

## 3. Сверка (до добавления)

- Сводный лист (contact sheet) всех картинок с подписями — посмотреть глазами каждую.
- Портрет со страницы персонажа: имя записи есть в тексте страницы (`pdftotext -f N -l N`); скан без текста —
  глазами (пол, подпись на карточке).
- Подписи: модель — её название; условное фото — «похожая модель»; фото с лицензией CC — автор и лицензия в
  подписи (сайт их показывает). `source` — книга и страница или откуда взято; локальных путей диска в `caption`
  и `source` нет.

## 4. Добавление

1. Сопоставление `checks/<YYYYMMDD>-<тема>/<имя>.json`: список `{target, src, kind, caption, source}`; вид —
   `art | portrait | card | handout | plan | illustration | photo`.
2. `python pipeline/art/add_images.py <сопоставление> --dry-run`, затем без него → копии и
   `<имя>-proposals.json`.
3. `python pipeline/integrate/apply.py <…-proposals.json>`; `python tools/check.py --changed` — ошибок 0.
4. Раздатка города — в своём разделе или у таблицы: `section` (history / tables / leads) или `table` (Р-166).
5. Сборка и проверка в браузере (навык `viewer-change`, раздел «Проверка»): картинка в колонке справа,
   лайтбокс открывается, значок «есть картинка» в списке.
6. Коммит: `kb/`, `app/art/`, `app/kb.html`, `checks/…`; запись в передаточный документ (навык `kb-release`).

## Показ (решения владельца)

- Картинки записи — колонкой справа в ширине карточки; таблицы рядом сужаются (Р-167).
- Клик — лайтбокс поверх страницы, стрелки листают галерею, мелкие фото вдвое крупнее (Р-168).
- Раздатка, планы, карточки — миниатюрами 150 px; фото предметов — на светлой подложке.
- В списках слева — значок «есть картинка» (Р-169).

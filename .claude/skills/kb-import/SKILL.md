# Перенос в базу: приём, план, извлечение (Р-139)

Конвейер — `pipeline/README.md`; правила записи — `docs/conventions.md`; решения — `docs/project-goal.md` §6.
Владелец отвечает по-русски, решения — по одному вопросу с рекомендацией.

## 0. Приём

1. Книга есть в `pipeline/source/books.json`? Нет — найти в `1_Библиотека` (Р-164; сначала каталог владельца
   `3_КБ\_Каталог.csv` — колонка «Библиотека» даёт папку сценария) и записать:
   `python pipeline/source/pages.py register <book_id> "<pdf>" --title "…" [--offset N]`
   (издание — по метке в начале имени файла, `pipeline/source/library.json`; `[RU-ИИ …]` — машинный перевод,
   не источник, отклоняется). Файлы Яндекс.Диска при первом чтении тянутся из облака — долго, в фоне.
2. Текст: `python pipeline/source/pages.py text <book_id>`; проверить смещение страниц на 2–3 страницах
   (`show`, `image`) и записать `offset`.
3. Опись: заголовки нужного диапазона (`show`, `grep`), что уже есть в базе (`Grep` по `kb/`), что
   из этого — новые записи, что — правки существующих.

## 1. План

Папка работы — `checks/<YYYYMMDD>-<тема>/`. В ней `plan.json` по образцу
`pipeline/briefs/examples/pobeg-iz-innsmuta-scenarios.json`:
`book_id`, `goal`, `decision` (Р-NN этой работы), `check_dir`, `models` (готовые записи-образцы),
`extra` (особые правила этой работы: схема id, что считать одной записью), `units` (имя, страницы,
цель, `owns` — какие файлы часть создаёт и правит, `sites`).

- Части не пересекаются по файлам. Общие записи (город, район, чужие сцены) не принадлежат никому —
  их правят через предложения.
- Перед запуском показать владельцу план одной таблицей и дождаться «да», если в плане есть новое
  решение (новая схема id, новый вид записи). Решение — строка Р-NN (навык `kb-decision`).

## 2. Извлечение

1. Задание каждой части: `python pipeline/briefs/make_brief.py <plan.json> <часть>` → `.cache/briefs/…md`.
2. Запустить по помощнику на часть параллельно (Agent; тип `kb-extractor`, если он доступен в сессии,
   иначе `general-purpose`). Промпт: «Прочитай задание `<путь>` и выполни его; в конце — отчёт по
   разделу Report». Задание уже содержит `docs/conventions.md` целиком — правила не пересказывать.
3. Пока помощники работают — короткие статусы владельцу.
4. Дальше — навык `kb-integrate`; картинки книги (портреты, раздатка, карты) — навык `kb-art`.

## Что владелец отложил

«Маски Ньярлатхотепа» (сюжет, групповые профили) и места других городов (Аркхэм и др.) — не начинать без его
слова. Список сделанного и несделанного — `docs/handoff/20261021-kb-state.md`, «Что сделано и что нет».

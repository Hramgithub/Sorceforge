# Repository guidance

This repository hosts the Sourcefold product under `Sourcefold/`.

- Read and follow `Sourcefold/AGENTS.md` for all project work.
- Apply `docs/governance/nri_goal_governance.md` to bundled goals.
- Apply `NRI_OCR_LAYOUT_RULES.md` whenever source layout or OCR traceability is
  in scope.
- Run project commands from `Sourcefold/` unless a command says otherwise.
- Keep the product name `Sourcefold`; `Sorceforge` is only the repository slug.
- Treat original source material, candidate inputs, and durable run evidence as
  governed artifacts. Do not delete or rewrite them as generated trash.
- Do not commit secrets, credentials, local runtime folders, caches, temporary
  logs, OCR overlays, or browser profiles.
- Preserve historical evidence byte-for-byte. Machine-specific paths inside
  immutable receipts describe the original run and are not instructions for a
  new machine.

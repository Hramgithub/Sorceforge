# Sorceforge

Репозиторий проекта **Sourcefold** (название продукта; `Sorceforge` — только
имя репозитория). Сейчас здесь строится **база знаний по «Зову Ктулху» 7-й
редакции**: данные — JSON в git, книги — источники, веб-помощник
`git_coc/web_helper_coc_gm` — образец и источник русских формулировок.

## Как смотреть и проверять

```bash
python tools/build_viewer.py
```

Собирает `app/kb.html` — просмотрщик с вкладками «Существа», «Персонажи»,
«Навыки»; открывается в браузере без сервера.

```bash
python tools/validate.py schemas/creature.schema.json kb/creatures/wolf.json
```

Проверяет записи по схеме (`creature`, `character`, `skill`).

## Что где

| Каталог | Содержимое |
|---|---|
| `docs/project-goal.md` | рабочий документ: цель, модель предметной области, решения, статус |
| `schemas/` | JSON-схемы и описание полей (`schemas/README.md`), примеры |
| `kb/` | данные базы |
| `app/` | просмотрщик (`kb.template.html` → `kb.html`) |
| `tools/` | сборка просмотрщика, валидатор схем |
| `pipeline/` | перенос из веб-помощника, MinerU, предложения из сценариев, массовые правки (`fix/`) |
| `checks/` | сверки с книгами: скрипты, результаты, инвентаризации |
| `proposals/` | предложения изменений из сценариев и решения по ним |
| `Sourcefold/docs/` | аудит идеи и реализации, приостановленный технический аудит, handoff (состояние до очистки) |

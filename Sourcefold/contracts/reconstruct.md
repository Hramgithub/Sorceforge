# Reconstruct Contract

Purpose: produce accepted structured source text from immutable source evidence.

## Inputs

- Original PDF, image set, or native source files.
- Source metadata and declared language.
- Reconstruction configuration and tool versions.

## Outputs

- Accepted Source Text.
- Source evidence manifest.
- Page or block acceptance ledger.
- Defect and uncertainty ledger.

## Required Preservation

- Reading order.
- Page markers and traceability anchors.
- Headings, emphasis, quotes, lists, tables, cards, and stat blocks.
- Numbers, dates, dice notation, formulas, mechanics, names, and definitions.

## Acceptance Gate

Reconstruction is accepted only when completeness, order, structure, and data
findings are resolved or explicitly waived with rationale.

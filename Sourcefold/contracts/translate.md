# Translate Contract

Purpose: produce a faithful Russian draft from accepted source text.

## Inputs

- Accepted Source Text.
- Reconstruction acceptance evidence.
- Terminology decisions and applicable glossary entries.
- Translation configuration, prompt identity, model/tool versions, and run
  metadata.

## Outputs

- Faithful RU Draft.
- Translation unit manifest.
- Terminology provenance.
- Preservation QA findings.

## Required Preservation

- Meaning and logical relations.
- Rule modality, subjects, conditions, and negations.
- Structure of headings, lists, tables, cards, and stat blocks.
- Numbers, dates, dice notation, formulas, mechanics, names, and definitions.

## Acceptance Gate

Translation is accepted as a draft only when preservation findings are resolved
or explicitly waived and the RU text remains traceable to accepted source units.

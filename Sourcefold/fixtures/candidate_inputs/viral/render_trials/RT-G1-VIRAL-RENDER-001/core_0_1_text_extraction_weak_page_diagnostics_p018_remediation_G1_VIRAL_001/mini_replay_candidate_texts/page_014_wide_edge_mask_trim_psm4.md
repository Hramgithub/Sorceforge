## p014_static_base_station_text_evidence

Static

These bits of equipment are set up early on and, with the

exception of the drone, remain at a single location.

Base Station

This is a custom industrial laptop with a Wi-Fi hub and satellite
uplink set up for live streaming. A deep cycle battery unit supplies
enough power for up to 12 hours of continuous broadcasting.

Keeper’s Notes
At the Keeper’s discretion, other devices may be charged off
the base station’s battery, but this obviously takes time that

the Investigators may not have.

## p014_cellular_repeaters_notes_text_evidence

Cellular Wi-Fi Repeaters/Transmitters (2)
Each provides Wi-Fi within a 300 Meter radius, and has a

battery unit that provides 8-10 hours of uninterrupted signal.

Keeper’s Notes

These are best set up in three key locations, the lighthouse,
the far side of the bridge, and the hospital tower. This provides
the greatest area of coverage for the investigation site. Note
that since the satellite signal is being routed through the Base
Station at the lighthouse, the hospital signal requires the
bridge transmitter to be active.

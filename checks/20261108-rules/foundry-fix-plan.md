# План правок журналов «Правила: …» мира «Зов Глубин Ктулху» по «Книге хранителя»

Задание: Р-178, Р-179 — ошибки журналов Foundry исправить по книге, домашние правила владельца не трогать.
Основа — сверка `checks/20261108-rules/foundry-vs-book.md` и записи `kb/rules/*.json` (тексты и страницы
русского издания). Состояние мира проверено выгрузкой 2026-11-08: с 2026-11-07 журналы не менялись, тексты —
`checks/20261107-foundry/journals/`. **Ничего не меняется до «да» владельца.**

## Как применить

1. **Резервная копия** — текущая выгрузка мира уже в git FoundryVTT (`content/world-sync/zov-glubin-ktulhu`,
   коммит `9a402ce`); при откате журналы восстанавливаются из неё.
2. **Правка в мире** (рекомендуется): через API Foundry в браузере под Гейм-мастером — скрипт обновляет только
   перечисленные ниже страницы (`JournalEntryPage.update`), удаляет одну и не трогает остальное. Мир работает,
   перезапуск не нужен. Владелец входит в мир во встроенном браузере, дальше правлю я.
   Запасной путь: тот же скрипт как макрос, владелец запускает его сам.
3. **Обратный путь Р-172**: выгрузка мира → ветка `foundry-sync/20261108` FoundryVTT → просмотр diff →
   `main` (push — после подтверждения) → деплой модуля по желанию владельца.

## 5. Ссылки «Источник» — на русское издание

На каждой странице блок «Источник» заменяется страницами русского издания из записей базы, с которыми
карточка сверена: «Глава N «…», «Раздел», с. X–Y». Полный список — приложение ниже (140 карточек). Особые случаи:

- страницы без правила книги («Ведите короткий журнал сессии», «Конфликт игроков решайте вне fiction»): «Совет
  владельца — в „Книге хранителя“ в таком виде нет» вместо неверных ссылок на гл. 10, с. 210 и гл. 1, с. 10;
- домашние правила (раздел 4): «Домашние правила владельца» и запись базы;
- «Упрощённый урон NPC» удаляется (№ 5).

## Чего план не касается

Карточки с вердиктом «упрощено», «нет в книге» (советы владельца) и мелкие добавки внутри книжных карточек —
не входят в разметку владельца; текст не меняется, меняется только «Источник». Таблицы мира («Безумие…», мании,
фобии, «Зоны попаданий») не трогаются.

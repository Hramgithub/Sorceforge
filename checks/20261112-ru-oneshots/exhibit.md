# «Экспонат „Новая жизнь“» (`eksponat-novaya-zhizn-ru`) — сверка переноса (часть exhibit)

Источник — русский оригинал автора (Николай Засов, конкурс коротких приключений Hobby Games), PDF 20 страниц с
текстовым слоем. С. 7 — текст «Информации для хранителя» напечатан по диагонали поверх иллюстрации (текстовый слой
перемешан), с. 17–18 — раздаточные материалы картинками (с. 17 повёрнута): прочитаны по изображениям страниц
(`pages.py image`, 100–200 dpi). Все статблоки (с. 14–16) и оружие (с. 13) сверены по изображениям.
Правила — 7-я редакция, `ruleset` core; эпоха — `1920s` и `modern` (книга: «как для 1920-х годов, так и для
современного времени»).

## Страницы

Смещение `eksponat-novaya-zhizn-ru`: **печатная = физическая** — на страницах нет номеров (проверено по изображениям
с. 1, 3, 7, 13–20).

## Опечатки книги (errata)

- Анастасия Калин: СКО 4 (по правилам 7); урон драки 1d3-2 при БкУ 0; Оценка 50% (25/6) → (25/10) исправлено.
- Арси Клодермайт: СКО 5 (по правилам 7, возраст не указан); урон драки 1d3-2 при БкУ 0.
- Мэнтос Великолепный: ПЗ 12 (по правилам 13); урон драки 1d3-2 при БкУ +1d4; доли Маскировки, Красноречия, Драки исправлены.
- Лир Сильвер: СКО 7 (по правилам 8); доли Криптографии, Оценки, Физики, Драки исправлены.
- Генри Купер: СКО 8 (по правилам 9); «Охотничий Нож 50% (25/100)» → (25/10) исправлено.
- Скиталец: ПМ 40 при МОЩ 95 (19) — оставлено как напечатано (большинства нет, Р-36).
- Металлические таблички: «потратить 1d4 времени» — единица времени пропущена.
- Мелкие словесные опечатки («Лож», «Улучшеный», «Металических», «кокана», «имею») исправлены молча в наших текстах (Р-39); в `raw` и в раздатках — как напечатано.

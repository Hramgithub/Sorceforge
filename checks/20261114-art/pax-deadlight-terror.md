# Картинки для записей (Р-241) — блок `pax-deadlight-terror`

Сопоставление: `pax-deadlight-terror.json` (85 картинок), предложения: `pax-deadlight-terror-proposals.json` (не применены),
атмосфера: `pax-deadlight-terror-atmosphere.json` (94 строки). Копии — `app/art/`. Вырезки из страниц: рамки — в
`.cache/art/<книга>/boxes.json`, `union-boxes.json` (Pax, Dead Light); у Dead Light и Innsmouth картинки вырезаны
из рендера страницы (200 dpi) по рамкам картинок из `pdftohtml -xml`, потому что в PDF они лежат цветоделёнными
каналами (DeviceN/Separation).

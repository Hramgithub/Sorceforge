# Картинки для записей (Р-241) — блок `scans-doors`

Книги-сканы: `dveri-vo-tmu-ru` («Двери во тьму», 142 стр.) и `chernovodnyy-ruchey-ru` («Черноводный ручей и Вышел
срок», 99 стр.). Все страницы просмотрены по листам миниатюр (40 dpi, по 9 страниц), страницы с картинками отрисованы
в 150 dpi, вырезки — в 200 dpi по рамкам `scans-doors-boxes.json` (доли страницы, страницы физические; `rotate` —
поворот раздаток, напечатанных боком; рамка из нескольких частей — части одной картинки, сложенные сверху вниз).
Сопоставление — `scans-doors.json` (72 картинки, 71 запись), предложения — `scans-doors-proposals.json` (не применены),
копии — `app/art/`. Страницы ниже физические (печатная = физическая + 1).

## Сомнения

- Чернов. с. 19: светящаяся фигура с посохом, обвитым зелёными щупальцами, без подписи. Сверка сценариев (`doors.md`)
  считает её «бесформенной массой у ручья», но на картинке человекоподобная фигура — не взята, записана в атмосферу.
- Двери с. 74: подпись «Гла’аки» — отдана записи сценария `lake-avatar-of-glaaki` (как в `doors.md`), а не общей
  `coc:creature:glaaki`. С. 93 «Бьякхи» — отдана `ties-mother-byakhee` (единственная взрослая бьякхи сценария).
- Двери с. 71: набросок «Служитель Гла’аки» — общей записи `coc:creature:servant-of-glaaki` (у неё уже есть картинка из
  веб-помощника); у записей сценария зомби (`lake-zombies`, «неудавшиеся служители») он не отдан.
- Общие записи с картинкой из «Аркхэма» получили вторую из этой книги: `greasy-spoon` (подписан на картинке),
  `temple-of-hope` (символ, другая картинка).
- Готовые сыщики «Вышел срок» (Дойл, Келли, О’Коннор, О’Грейди, Мёрфи) в задании не названы — взяты, потому что их
  листы напечатаны в этой книге и картинок у записей нет; при желании убрать — 6 строк сопоставления `chr-*`.
- Вырезки из сканов: у пары портретов с листа набросков (Смиты, Брофи) в кадр попадают края соседних лиц.

# Картинки для записей (Р-241) — блок `wave3-c`

Сопоставление: `wave3-c.json` (19 картинок, 18 записей), предложения: `wave3-c-proposals.json` (не применены),
атмосфера: `wave3-c-atmosphere.json` (106 строк). Копии — `app/art/`. Вырезки из страниц — по рамкам в
`.cache/art/<книга>/boxes.json` (`crop-*`; `chk-*` — только для сверки, не в сопоставлении).

Заявление о нейросети (Р-240) искалось в тексте всех 24 книг (выходные данные, предисловие, титры). Найдено только у
«Шанса на чудо» (с. 2: «Изображения — сгенерированы с помощью NanoBanana 2»): из книги ничего не взято, все её
картинки — в атмосфере с пометкой. У остальных книг такого заявления нет (у части книг выходных данных нет вовсе).

Итого: портреты 3, арт 3, раздатка 10, иллюстрации 3; атмосфера 106 строк.

# Сверка находок `context.no_description` с книгами (2026-11-14)

Проверено 465 находок из `findings.json`: 444 персонажа и 21 книга (`tome`). Записи базы не менялись.

## Главный вывод

**Все 444 персонажа описание имеют.** Проверка его не видит, потому что ищет не там:

- биография персонажа по схеме лежит в `legend` (`schemas/character.schema.json`: «Биография — в legend»), а `tools/completeness.py` (строки 302–305) поле `legend` не читает вовсе;
- `background` у персонажа — объект с полями листа сыщика (`description`, `ideology`, `traits`, `significant_people`, `secret`…), а функция `ru()` берёт у объекта только ключи `ru`/`en`. Поэтому заполненный `background.description` считается пустым.

Из 444 персонажей: только `legend` — 290, `legend` и `background` — 87, только `background` — 67. Ни одной записи без того и другого нет.
Самые короткие тексты — 38–120 знаков (16 записей). По книге это персонажи, которых называют одной строкой (жена, сын, раб, смотритель), и запись передаёт всё, что о них сказано.

**21 книга из «Книги хранителя» (`keeper-rulebook-ru`) действительно без описания, и это верно.** Все они взяты из таблицы XI «Книги Мифов» (физ. с. 217–219: название, язык, год, автор, недели, Рассудок, МКН, МКП, ЗМ). Поиск по тексту книги находит каждое название только в этой таблице. Текста для описания книга не даёт.

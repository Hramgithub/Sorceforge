# Сверка сценариев с книгой — часть `rulebooks`

Пять книг, 15 записей сценариев: `pulp-cthulhu-en` (4), `keepers-companion-en` (3), `keeper-rulebook-ru` (2),
`temnye-veka-tri-stsenariya-ru` (3), `tri-koshmarnykh-vechera-ru` (3). У каждого сценария есть файл сверки переноса
с таблицей «Заголовок книги | Страница | Где в базе»; каждый заголовок в нём есть.

Как сверено:
- страницы сценариев прочитаны по текстовому слою (`pdftotext` по физическим страницам; скан «Книги хранителя» — с
  шумным слоем, его прочитали по изображениям ещё при переносе);
- все имена собственные со страниц сценария (английские — с заглавной буквы, русские — по основе слова) проверены
  по базе (`name`, `aliases`, тексты записей) и по разделу «Не взято» файла сверки. Без записи остались только
  упомянутые мимоходом лица и места, которые файл сверки перечисляет в «Не взято»: улицы, исторические владельцы ящика
  Пандоры, экипаж «Кулиджа» (таблица у парохода), Хейли и Брайан (сыщики примера правил);
- у каждого сценария выборочно сверены 4–10 чисел и ключевых фактов: все награды и потери Рассудка финала, потери
  Рассудка в сценах, статблоки 1–2 существ или персонажей, параметры книг Мифов, тексты раздаток;
- картинки — по записям и по разбору картинок (`checks/20261114-art/pulp-companion.md`, `wave2-rules.md`,
  `wave3-a.md`, `checks/20261114-art-recent/`); у всех `image` и `images` пяти книг файлы на месте.

Страницы ниже — печатные, кроме оговорённых.

## Замечания (не потери)

- Механические находки `report.md` по этим книгам формальны: сцены без участников — осмотры мест без людей
  («Изыскания о ящике», «Место перестрелки», «Хижина: обыск дома» и др.); сцены без места — работа в библиотеке,
  видения, общий ход («Изыскания перед аукционом», «Собирая кусочки», «Бледный человек»); сцены без итога —
  финальные («Последствия», «Заключение»), итог у них в `conclusion` сценария. «Страница без записей» физ. 149 Pulp
  Cthulhu — лист портретов «Дезинтегратора»: портреты взяты в записи персонажей.
- Не взяты по решению (Р-241, атмосфера): сцены «Демонстрация» и «Чудовища в тумане» (Pulp, физ. 151, 154); рисунки
  «Каменные ящики и призраки», «Кристалл», «Тело в лесу» («Среди древних деревьев», англ. издание физ. 354, 358, 361);
  рисунок револьвера и повтор портрета Джейкоба («Синее сияние»); монеты, фонарик, револьвер (Keeper's Companion).
  Содержание этих рисунков есть в текстах записей.
- Раздатки 7, 9, 10 «Ящика Пандоры» — без картинки (на листах с 6 и 8), их тексты в записях полные; карточки мотивов
  «Среди древних деревьев» и раздатки «Багровых письмен» — текст книги без отдельного рисунка.
- Опечатки и расхождения книг уже в `errata` и `corrections` записей — см. файлы сверки переноса.

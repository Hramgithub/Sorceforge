# Целостность сценариев — участок `singles-1`

Книги с одним сценарием, 1–17 по алфавиту (`units.md`). Для каждой книги: строка и находки в `report.md`, таблица
покрытия заголовков из сверки переноса (`checks/20261112-*/<часть>.md`), текст книги постранично (`pages.py show`; сканы
«Эликсир жизни» и «Идол Тота» — заново распознаны tesseract, «Благослови детей его» — `.cache/art/…/text.txt`), записи
книги и записи справочника, на которые они ссылаются. Сверено:

- **имена** — все имена собственные из текста книги против текста записей (вне записей остались только титры,
  благодарности, переносы строк и обычные слова с заглавной буквы);
- **числа** — ПЗ и МОЩ каждого статблока против страниц-источников (несовпадения разобраны по изображениям страниц:
  статблоки-картинки «За гранью тьмы», клетки ПЗ «Манко Капака», «ЗДОРОВЬЕ» в «Холодном урожае», распознавание «Идола
  Тота»); выборочно — потери Рассудка, таблицы, раздатки;
- **картинки** — все картинки PDF, которые проход картинок (Р-241) не брал (меньше 250 px, площадь меньше 120 000, картинка
  во весь лист), просмотрены листами-превью; картинки сканов — по изображениям страниц.

Находки `scenario_check` по этим сценариям, кроме `clues.empty`, — `low` (`scenes.no_outcome`, `scenes.no_people`,
`scenes.no_place`, `clues.unused`): текст сцен сюжет, участников и итоги содержит, это структура, не потеря.

# Сверка сценариев с книгой — часть `singles-4`

Семнадцать книг с одним сценарием (книги 52–68 списка `units.md`). Для каждого сценария есть файл сверки переноса с
таблицей «Заголовок книги | Страница | Где в базе» (`checks/20261112-ru-oneshots/*.md`, `checks/20261112-owner-books/*.md`,
`checks/20261112-starter-set/*.md`, `checks/20261113-ru-rest/japan.md`). Каждая строка этих таблиц проверена по базе:
записи, на которые они ссылаются, существуют, сцены и шаги сценария на месте. Книги читались по текстовому слою
(`pages.py show --physical`); сканы без текстового слоя (три книги «Стартового набора», «Тайник Бутлегеров»,
«Рождественская вечеринка») — по распознаванию tesseract и уменьшенным страницам. Картинки проверены по списку изображений
страниц (`pdfimages -list`, порог импорта Р-241: сторона меньше 250 px или площадь меньше 120 000 px — не брались) и по
листам уменьшенных страниц. Выборочно сверены числа: статблоки (Артур Стоун, Дональд Бонс, Николай, Ота Наоя с
Уклонением, Тавил, Саймон Бакстер, Роланд Вашингтон, Пётр Дацюк, Хозяин стола, Альбион Фицджеральд, Роджер Дэниелс,
Рыжий Джейк, Мелодиас Джефферсон, Дуглас Кимбол), тексты раздаток («Таймс» о слепых ветеранах, записка Нунцио, «Стомп
1–3», «Пригласительное письмо»), таблица «Болезни». Всё совпало с книгой.

Страницы ниже — физические страницы PDF («физ.»); где печатный номер другой, он дан рядом.

## Замечания (не потери)

- Механические находки `report.md` по этим книгам — формальные: сцены без итога (осмотры, события леса, звонки), без
  участников (осмотры пустых мест) и без места (сны, поиски по телефону).
- «Тайник Бутлегеров»: стоит записать PDF раздаток автора отдельной книгой (или источником этой) и перенести три текста
  раздаток и план первого этажа отеля — вопрос уже стоит в файле сверки переноса.
- Сканы «Стартового набора» и «Тайника Бутлегеров» стоит добавить в волну картинок Р-241 вручную (и их атмосферу — в
  `pipeline/art/atmosphere.json`), как предложено для «Дверей во тьму» в `doors.md`.

## Руда паскуаллия

### Свойства паскуаллия

| Свойство | Значение |
|---|---|
| **Атомный вес** | 322,430532 |
| **Атомный номер** | 124 |
| **Удельный вес** | 31,4 (примерно в 1,6 раза тяжелее золота или урана) |
| **Цвет** | плеохроизм: кажется двухцветным — зелёным и чёрным |
| **Блеск** | от металлического до смоляного и тусклого |
| **Текстура** | в сыром виде очень шершавая, как наждачная бумага; кроме того, жирная на ощупь — даже после того как из него сделали что-то другое |

| **Сингония** | кубическая, 6/m bar 4 3/m |
| **Габитус** | крупные гроздевидные (ботриоидальные), тёмные, пластинчатые почковидные агрегаты; чётких октаэдрических и кубических кристаллов мало |
| **Спайность** | редкая в любом направлении из-за общей хрупкости |
| **Твёрдость** | по шкале Мооса по стойкости к царапанию — больше десяти: твёрже алмаза (в 1930-х ничто известное человеку его не царапает) |
| **Ковкость** | проба Бринелля для определения общей прочности бесполезна: пока нет металла, достаточно твёрдого, чтобы оставить на нём отпечаток |
| **Химическая активность** | не поддаётся крайним воздействиям воздуха, влаги, кислот и растворителей; однако при детонации быстро меняется химически, после чего взрывается |
| **Сопутствующие минералы** | нет |
| **Температура плавления** | около 4660 °C (для сравнения: нынешний рекордсмен вольфрам плавится примерно при 3410 °C) |
| **Прочее** | не радиоактивен; очень хрупок: превысив предел нагрузки, не гнётся, а раскалывается |
| **Известные месторождения** | Брокен-Хилл, Вермонт. Предполагают, что залежи есть в Андах, Аппалачах, Гималаях и, возможно, глубоко под земной корой |

*Прим. перев.: «6/m bar 4 3/m» — как напечатано (видимо, искажённая запись класса симметрии кубической сингонии, 4/m 3̄ 2/m).*

Для FOC у руды есть одно поистине поразительное свойство: при комнатной температуре она сверхпроводник — то есть её электрическое сопротивление при 25 °C равно нулю (пока неслыханное для металла свойство). Как сверхпроводник, она к тому же диамагнетик (её отталкивают магнитные поля). Применений у такого элемента не счесть: он может очень пригодиться в вооружении и броне, для передачи электричества, для поездов, которые идут над намагниченными рельсами, для нержавеющих металлов и так далее.

Ми-го куда больше занимают удивительные возможности, которые даёт этот металл в конфигурации Врат. Если придать этому материалу определённые формы и углы, две реальности можно скрепить друг с другом, чтобы они сосуществовали в одном пространстве, — и мгновенно перемещаться из одного места в другое без обычной траты пунктов магии. Единственный недостаток — руды ограниченное количество, а чтобы зарядить даже небольшой кусок, нужно ужасающее количество МОЩ. Кроме того, руду трудно найти: даже ми-го с трудом отыскивают её своими машинами. Чаще всего руда встречается лишь мелкими, редко разбросанными вкраплениями.

Твои папки произведений — список `checks/20261124-library-audit/list-{UNIT}.txt` (пути относительно `1_Библиотека`).
Автоматический разбор редакций по текстовому слою всех PDF — `checks/20261124-library-audit/editions.json` (поля: path, label, pages, words, years, score7, score6, stats_small, stats_big, verdict) и сводка `editions.md`.

Для каждой своей папки:
1. Прочитай `_описание.md` (карточку).
2. Посмотри файлы папки (включая подпапки «Прегены», «Раздатка», «Карты»). По основному PDF прочитай титул, выходные данные, оглавление и начало: `pdftotext -f 1 -l 8 -enc UTF-8 "<pdf>" -` (для сканов — `pdftoppm -r 60 -f N -l N -png "<pdf>" <scratch>\x` и посмотри картинку). Временные файлы — только в своей подпапке scratchpad `audit-{UNIT}` (`C:\Users\user\AppData\Local\Temp\claude\634ee58b2ba30d51\ae8b1f86-02a4-4e80-b497-822ff11e3794\scratchpad\audit-{UNIT}`).
3. **Редакция:** сверь метку каждого PDF с содержимым. Если `editions.json` показывает расхождение (verdict против метки) или файл — скан/без текста, или метка без редакции («[EN]») — найди страницу со статблоком или правилами и реши сам: 7e (характеристики 15–90, «50% (25/10)», Hard/Extreme, Build, Luck, bonus/penalty die, © 2014+), 6-я/5-я (характеристики 3–18, «x5», Resistance Table, «halved»), или книга без игровых статов (рассказы, путеводитель — тогда редакция по выходным данным/году). Помни ловушки: в 6e-книгах бывает приложение с 7e-статами и наоборот (London 3 — 7e с приложением 6e); Chaosium переиздавал старые книги «для 7e» (Cthulhu by Gaslight 3rd, Pulp…). Одинаковые файлы (md5) под разными метками — отметь.
4. **Карточка:** проверь «Кратко», «Для игры» (год и место, игроки, сессии, про что), «Сценарии внутри», `kind`, `era`, `editions` против книги. Ищи именно ошибки: другое произведение описано, неверная эпоха/место, сборник назван ваншотом, пропущены сценарии внутри, неверный издатель/год, неверная редакция в `editions`. Мелочи стиля не нужны.
5. Пиши итог в `checks/20261124-library-audit/desc-{UNIT}.md` по формату README (одна строка на находку; в конце — «без замечаний: N папок»). Пиши по ходу работы (дописывай файл), чтобы при обрыве ничего не пропало.

В конце — короткий отчёт: сколько папок проверено, сколько находок по категориям, самые важные (неверная редакция у файлов, другое произведение в карточке).

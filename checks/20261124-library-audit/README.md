# Сверка каталога библиотеки «Зов Ктулху» (2026-11-24)

Владелец: «мы несколько раз ловили ошибку — неверного определения редакции и о чём произведение; пройдёмся по всему каталогу и перепроверим».
Работа только на чтение: файлы библиотеки (`НРИ\1_Зов Ктулху\1_Библиотека`) не меняются; итог — список правок, владелец решает.

## Что проверяется

1. **Редакция** каждого PDF — метка в начале имени (`[EN 7e]`, `[EN 6e]`, `[RU 7e]`, `[RU-фан 7e]`…) против содержимого:
   - 7-я редакция: характеристики 15–90 с шагом 5, доли «50% (25/10)», трудная/чрезвычайная проверка, бонусная/штрафная кость,
     Комплекция (Build), Удача, повторная проверка; копирайт 2014+ (7e вышла в 2014);
   - 6-я и раньше: характеристики 3–18, «x5», таблица сопротивления, «halved Spot Hidden», бонус к урону без Комплекции;
   - один и тот же файл (md5) под разными метками.
   Автоматическая часть — `editions.md` (скрипт по текстовому слою); сканы без текста проверяются по картинке страницы со статами.
2. **Карточка** `_описание.md` каждой папки произведения против книги: «Кратко», «Для игры» (год и место, игроки, сессии,
   про что), «Сценарии внутри», вид (`kind`), `editions` — по титулу, выходным данным, оглавлению, введению и первой главе.

## Как пишется итог (каждая часть — свой файл `desc-<часть>.md`)

По одной строке на карточку с находкой (карточки без замечаний — одной строкой «без замечаний: N» в конце):

`- <раздел>\<папка> — <что не так> → <как правильно> (<на чём основано: стр. N / титул / оглавление / © год>) [уверенность: высокая|средняя|низкая]`

Категории: **редакция** (метка файла неверна), **вид** (сборник/кампания/ваншот/не сценарий), **эпоха/место**, **сюжет** (кратко неверно или про другое
произведение), **сценарии внутри** (неполный/неверный список), **дубль** (то же произведение в другой папке), **не по системе**, **прочее**.
Пути — относительно `1_Библиотека` (без `C:\…`).

# Памятка по морскому бою для Хранителей и сыщиков

## Что мне делать?

**Получить наветренное положение (weather-gage)**
Корабль с наветренной стороны имеет преимущество наветренного положения и сам решает, сближаться ли для боя.

**Маневрировать и чинить**
Чтобы корабль шёл куда нужно, нужны паруса, такелаж, руль и люди, которые с ними работают. Держите их в порядке и заделывайте любые пробоины ниже ватерлинии!

**Стрелять из пушек!**
Большинство пушек у кораблей — по бортам, и кораблю нужно развернуться, чтобы навести их на неприятеля. Уязвимее всего корабль с кормы. Бортовой залп в корму может быть смертельным.

Огонь поверху (особенно книппелями) рушит паруса, мачты и такелаж. Огонь вдоль палубы (особенно картечью) убивает экипаж. Огонь по корпусу (особенно ядрами) топит корабль.

**Мушкеты и пистолеты**
Пока расчёты стреляют из пушек, другие моряки и морские пехотинцы забираются на площадки на мачтах — «марсы» — и стреляют из мушкетов по офицерам и орудийным расчётам неприятеля.

**Абордаж**
Если стрельба из пушек издали не помогает или невозможна, идите на абордаж. Подойдите борт к борту к другому кораблю, раздайте всем пистолеты, топоры и сабли и попробуйте захватить корабль в рукопашной!

## Какой навык использовать?

Большинство действий, не перечисленных здесь, покрывают ЛВК и СИЛ.

| Действие | Навык или характеристика |
|---|---|
| ***Манёвры*** | |
| Подняться на ванты и выйти на реи | Лазание, Прыжки |
| Связать и срастить порванные тросы | Механика |
| Поставить паруса или повернуть руль | Парусное дело |
| ***Стрельба из пушек*** | |
| Откатить и выкатить орудие | ЛВК, СИЛ |
| Навести, пробанить, зарядить, насыпать затравку и выстрелить | Стрельба (пушка) |
| Починить сломанное орудие | Механика |
| ***Стрельба из мушкетов*** | |
| Зарядить, прицелиться и выстрелить с марса | Лазание, ЛВК, Стрельба (мушкет) |
| ***Абордаж*** | Лазание, Уклонение, Ближний бой (драка), Ближний бой (холодное оружие), Стрельба (пистолет), Прыжки |
| ***Вести за собой или подбадривать группу моряков*** | Запугивание, Убеждение |
| ***Сортировка раненых*** | Первая помощь, Медицина |
| ***Увернуться от летящих щепок и падающего такелажа*** | Уклонение, Удача |
| ***Сохранить присутствие духа в бою*** | МОЩ, Рассудок |

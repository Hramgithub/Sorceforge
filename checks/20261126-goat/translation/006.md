# Предупреждения о содержании

| Сценарий | Темы |
|---|---|
| Дева, Мать, Старуха | Телесный ужас, натуралистическое насилие, одиночество и изоляция, угроза подросткам и причинение им вреда, упоминания жестокого обращения и его повторения из поколения в поколение, изображение повешенного. |
| GOAT-фитнес | Телесный ужас, одержимость фитнесом и сатира на крайности культуры спортзалов. |
| Козье снадобье | Решения, принятые без согласия тех, кого они касаются, деятельность культа, телесный ужас. |
| Сделка ведьмы | Телесный и психологический ужас, вина, искупление и дегуманизация. |
| In Sorte Diaboli | Телесный ужас, каннибализм, противостояние между игроками, членовредительство. |
| Монастырь Санкта Мария Лактанс | Телесный ужас, религиозные отсылки и образы. |
| Фестиваль Всематери | Женский гнев, сексуальная символика (без сцен секса), сексизм, символика плодородия, теории заговора, возможное насилие над подростками. |
| Дом плоти | Телесный ужас, натуралистическое насилие, пытки, темы для взрослых, самоубийство, каннибализм. |
| Служить на небесах | Телесный ужас, возможное противостояние между игроками, кровь и натуралистическое насилие, смерть, газлайтинг, депрессия. |
| Нос Галан Гайав. Канун зимы | Человеческие жертвоприношения, алкоголизм, возможны телесный ужас и противостояние между игроками. |
| Невостребованные письма из сада | Травма в отношениях, ужас выживания, увечья животных, насилие, возможное противостояние между игроками, травма, возможное самоповреждение, угроза подросткам и причинение им вреда, самоубийство, расизм и классовая дискриминация. |
| Мать тысячи младых | Телесный ужас, темы для взрослых, гибель подростков. |

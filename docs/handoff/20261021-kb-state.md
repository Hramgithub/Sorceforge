игнорируется — скрипты сами переключают вывод на UTF-8.

## Как работаем с владельцем

- Отвечать по-русски, в чат — только итоги; пока работает фон — короткие статусы.
- Любой готовый артефакт — коммит и push в `main`; force push только с подтверждения.
- Решения — по одному вопросу с рекомендуемым вариантом; ответ — строка Р-NN в
  `docs/project-goal.md` §6 и коммит (навык `kb-decision`).
- Большие объёмы — партиями по помощникам (навык `kb-import`); помощники не коммитят.
- Числа не придумываем: всё сверяется с изображением страницы; спорное — в `errata`.

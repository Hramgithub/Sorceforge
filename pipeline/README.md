# Конвейер переноса книги в базу (Р-139)

Каждая книга проходит одни и те же этапы. Правила записи — `docs/conventions.md`; журнал решений —
`docs/project-goal.md` §6.

| Этап | Что на выходе | Чем |
|---|---|---|
| 0. Приём | книга записана в `pipeline/source/books.json`, текстовый слой в кэше, соответствие печатных и физических страниц (`offset` или, если в скане пропущены страницы, `page_map`), опись заголовков | `pipeline/source/pages.py text / pagemap / show / grep / image` |
| 1. План | части работы: страницы, цель, чьи файлы; файл плана в папке проверки | примеры — `checks/20261103-map-spots/plan.json`, `checks/20261105-names/plan.json`, `pipeline/briefs/examples/` |
| 2. Извлечение | записи частей и файлы предложений правок общих записей | задание — `pipeline/briefs/make_brief.py <план> <часть>`; помощник — `.claude/agents/kb-extractor.md`; навыки — `.claude/skills/` |
| 3. Нормализация | кубы, термины, Рассудок и Скорость словами, флаг опечаток, формат — только в новых и изменённых файлах | `pipeline/fix/normalize_dice.py`, `normalize_terms.py`, `attribute_words.py`, `errata_flag.py` — все с `--changed` |
| 4. Сведение | предложения применены, изменения — в `corrections` | `pipeline/integrate/apply.py <файлы предложений>` |
| 5. Проверка | схемы, ссылки, правила записи, формат; покрытие заголовков книги | `python tools/check.py`; таблицы покрытия в папке проверки |
| 6. Выпуск | просмотрщик, коммит, передаточный документ; выкладка — по просьбе владельца | `python tools/build_viewer.py`, `tools/deploy_kb.ps1 -Build` |

## Папки

- `source/` — книги и чтение их страниц (кэш — `.cache/sources/`, не в git).
- `briefs/` — шаблон задания помощнику и сборка задания из плана; задания пишутся в `.cache/briefs/`.
- `integrate/` — формат предложений правок и их применение.
- `art/` — картинки записей: `add_images.py <сопоставление.json>` ужимает копии в `app/art/` и пишет предложения (Р-165).
- `fix/` — массовые исправления. Всегда с указанием, что трогать: файлы, `--changed` или `--all`; файлы вне `kb/` не принимаются.
- `migrate/`, `extract/`, `propose/`, `mineru/` — инструменты прежних переносов (веб-помощник, Malleus, MinerU).

# Конвейер переноса книги в базу (Р-139)

Каждая книга проходит одни и те же этапы. Правила записи — `docs/conventions.md`; журнал решений —
`docs/project-goal.md` §6.

| Этап | Что на выходе | Чем |
|---|---|---|
| 0. Приём | книга записана в `pipeline/source/books.json`, текстовый слой в кэше, опись заголовков | `pipeline/source/pages.py text / show / grep / image` |
| 1. План | части работы: страницы, цель, чьи файлы; файл плана в папке проверки | пример — `pipeline/briefs/examples/` |
| 2. Извлечение | записи частей и файлы предложений правок общих записей | задание помощнику — `pipeline/briefs/make_brief.py <план> <часть>` |
| 3. Нормализация | кубы, термины, формат — только в новых и изменённых файлах | `pipeline/fix/normalize_dice.py --changed`, `normalize_terms.py --changed` |
| 4. Сведение | предложения применены, изменения — в `corrections` | `pipeline/integrate/apply.py <файлы предложений>` |
| 5. Проверка | схемы, ссылки, правила записи, формат; покрытие заголовков книги | `python tools/check.py`; таблицы покрытия в папке проверки |
| 6. Выпуск | просмотрщик, коммит, передаточный документ; выкладка — по просьбе владельца | `python tools/build_viewer.py`, `tools/deploy_kb.ps1 -Build` |

## Папки

- `source/` — книги и чтение их страниц (кэш — `.cache/sources/`, не в git).
- `briefs/` — шаблон задания помощнику и сборка задания из плана; задания пишутся в `.cache/briefs/`.
- `integrate/` — формат предложений правок и их применение.
- `fix/` — массовые исправления. Всегда с указанием, что трогать: файлы, `--changed` или `--all`.
- `migrate/`, `extract/`, `propose/`, `mineru/` — инструменты прежних переносов (веб-помощник, Malleus, MinerU).

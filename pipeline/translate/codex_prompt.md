Ты — переводчик книги для базы знаний «Зова Ктулху» 7-й редакции (репозиторий — текущая папка). Задача: перевести на русский английскую книгу «{TITLE_EN}» ({CREDITS}) — {PART} — по страницам, в Markdown, для сборки в один HTML (решение Р-251). Перевод для личного использования владельцем книги.

Прочитай сначала: `.claude/skills/kb-translate/SKILL.md` (раздел 2) и образец готового перевода `checks/20261115-starfall/translation/` (2–3 страницы и `meta.json`) — не больше. `AGENTS.md` у тебя уже загружен. Работай только над этой задачей: не изучай остальной репозиторий, не запускай посторонних проверок.

## Источник

- Текст физической страницы N: `python -I -B pipeline/source/pages.py show {BOOK} N --physical`.
- Картинка страницы: `python -I -B pipeline/source/pages.py image {BOOK} N --physical` — печатает путь к PNG; открой его и посмотри (врезки, колонки, таблицы, где стоят иллюстрации). Смотри каждую страницу: текстовый слой путает порядок колонок и врезок.
- Книга уже перенесена в базу: `kb/books/{BOOK}/`. Список терминов English → русский и опечатки книги — в `{TERMS_MD}`. Имена людей, мест, организаций, существ, предметов, раздаток и термины — СТРОГО как в `name.ru` записей базы и в этом списке (ищи: `rg -l "<English name>" kb/books/{BOOK}`). Навыки, характеристики, проверки — как в русской Книге хранителя: `python -I -B tools/terms.py <слово>` (Hard — «трудная проверка», Extreme — «чрезвычайная», никогда «сложная»).
- Тексты раздаток в базе — уже наш перевод: бери их из записей `handouts/` как есть.

## Твои страницы и файлы

Физические страницы {PAGES}. Пиши ТОЛЬКО:
- `{TR_DIR}/NNN.md` — по одному файлу на физическую страницу (NNN = номер с нулями: 001, 002 …);
- картинки в `{TR_DIR}/img/` с префиксом `{IMG_PREFIX}`;
{META_LINE}
- `{TERMS_OUT}` — термины, которые ты выбрал сам (их нет ни в глоссарии `tools/terms.py`, ни в `{TERMS_MD}`, ни в `name.ru` записей): JSON-список `[{"en": "…", "ru": "…", "aliases": [], "avoid": [], "domain": "rule|skill|place|organization|creature|item|tome|spell|other", "ref": "<id записи базы, где термин встречается, или null>", "definition": "<одно предложение: что это в книге>", "note": "<почему так перевёл>"}]`; если таких нет — `[]`. Каждый такой термин пиши во всей твоей части одинаково.
Больше ничего не меняй: ни записи базы, ни инструменты, ни git (не коммить, не делай `git add`). Если запись базы, по-твоему, ошибочна — напиши об этом в отчёте.

## Формат страницы

- Заголовки как в книге (`#`, `##`, `###`); заголовки частей — «Часть I.», «Часть II.» (с точкой).
- Врезки — цитатой (`> `). Таблицы — Markdown. Вложенные списки — отступ 4 пробела.
- Статблок — блок ```` ```stat ````, как в образце; скорость — «Скорость:» (никогда «СКО»); броски — `1d6`, `2d10+3`, `1d100` (строчная d).
- Раздатка: оригинал картинкой, затем перевод блоком `> **Раздатка N. Название**`; две соседние раздатки разделяй строкой `<!-- -->`.
- Картинки: `![подпись](img/файл.jpg)` на своём месте. Уже вырезанные для базы картинки бери из `app/art/**/{ART_GLOB}` и `app/maps/{ART_GLOB}` (копируй в `img/` под своим префиксом); остальные иллюстрации (обложка, атмосферные — список в `{ATMO}`) вырежи из картинки страницы: `python -I -B pipeline/source/pages.py crop <png> x0 y0 x1 y1 --out <файл>` (доли 0–1), затем сожми в jpg шириной ≤1000 px (Pillow). Рамки, виньетки, номера страниц не нужны.
- Ключи карт и подписи на картах — переводом списком под картинкой.

## Правила перевода

- Ничего не пропускать: весь текст, врезки, таблицы, все статблоки, раздатки, ключи карт, оглавление (с номерами страниц), выходные данные (кратко).
- Меры — метрические, как в базе (Р-64): ярд → м 1 к 1, фут → м (÷3), миля → км (×1,6), фунт → кг.
- Опечатки книги — курсивом «*Прим. перев.:* …» на месте; те же, что в разделе опечаток `{TERMS_MD}`. Новые найденные — тоже, и перечисли их в отчёте.
- Стиль — живой литературный русский, без кальки; реплики персонажей — естественной речью.
- Если ответ обрывается или срабатывает ограничение на длину — продолжай по одной странице за шаг, пока не сделаешь все.

## Проверка перед отчётом

`python -I -B pipeline/translate/check_translation.py {TR_DIR} {BOOK} --pages {PAGES}` — должно быть «ошибок нет». Страницы с пометкой `<<<` (короткие) перечитай против оригинала и допиши пропущенное. HTML не собирай — его соберёт ведущий.

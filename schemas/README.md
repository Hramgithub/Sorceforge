# Схемы базы знаний (спецификация v0)

Спецификация данных базы знаний по «Зову Ктулху» 7-й редакции. Каждое правило
здесь — следствие решения из журнала `docs/project-goal.md` §6 (номер Р-NN
указан рядом).

## Файлы

| Файл | Что это | Данные |
|---|---|---|
| `common.schema.json` | общие типы: id, текст, значение с исходной записью, процент, урон, источник, исправление, опечатка, связи, способность, оси, качество, общий статблок | — |
| `creature.schema.json` | существо: зверь, тварь Мифов, божество, воплощение, сверхъестественное | `kb/creatures/`, `kb/books/<книга>/creatures/` |
| `character.schema.json` | персонаж: NPC для Хранителя и/или готовый сыщик | `kb/characters/`, `kb/books/<книга>/characters/` |
| `skill.schema.json` | навык | `kb/skills/` |
| `occupation.schema.json` | профессия | `kb/occupations/` |
| `spell.schema.json` | заклинание | `kb/spells/` |
| `tome.schema.json` | книга Мифов, оккультная книга | `kb/tomes/` |
| `weapon.schema.json` | оружие | `kb/weapons/` |
| `location.schema.json` | локация: город, район, здание, место, область | `kb/locations/` |
| `examples/` | по примеру на каждый вид записи | — |

Проверка (без внешних библиотек):

```powershell
python tools\validate.py schemas\<вид>.schema.json <файлы>
```

## Общие правила

- **Идентификатор** — `coc:<вид>:<slug>`; для записей конкретной книги —
  `<книга>-ru/<вид>/<slug>`. По id ссылаются связи, профессии, навыки.
- **Текст** — `{ru, en}`: `ru` обязателен. Описательный текст и механики — по-русски;
  если русского источника нет, это наш перевод с флагом `translated` (Р-21, Р-33).
  Не переводятся английские имена (`name.en`), псевдонимы, оригинальные названия
  заклинаний.
- **Числа** — рядом с разобранным значением всегда лежит запись `raw`. Кубы — `6d6`
  (Р-27). Сокращения характеристик — как в «Книге хранителя»: СИЛ, ВЫН, ТЕЛ, ЛВК,
  НАР, ИНТ, МОЩ, ОБР; ПЗ, ПМ, БкУ.
- **Источник истины для чисел** — Malleus Monstrorum 7e: он важнее «Книги
  хранителя» (Р-22) и карточек Keeper Deck (Р-23). Прежнее значение — в `corrections`.
- **Опечатки книги** — `errata`: поле, что напечатано, что ожидалось, пояснение,
  `fixed`. Исправляются: неверные половина/пятая (Р-35), числа, которые расходятся
  с двумя согласованными (Р-36), среднее против броска (Р-37), противоречие таблицы
  и однозначного текста (Р-38); остальное — как напечатано. В списке только важное
  ведущему (Р-39).
- **Источник** — `sources[]`: книга, физическая и печатная страница, страница начала
  статьи (`entry_page`), пояснение (`note`), способ получения, сверено ли.
- **Качество** — `quality`: флаги `translated` («перевод»), `parse_uncertain`
  («опечатка книги» — стоит ровно у записей с `errata`), `incomplete` («неполно» —
  в книге нет данных), `needs_review`; короткое примечание для ведущего.
- **Формат файла** — UTF-8, отступ 2, LF (`pipeline/fix/normalize_terms.py`).

## Связи (`relations`)

Связь хранится в одной записи, обратную сторону показывает просмотрщик (Р-30, Р-42).

| Тип | Значение |
|---|---|
| `form_of` | другая форма, стадия или вид того же существа |
| `instance_of` | особь вида: персонаж или существо, для игры которым берётся статблок вида (Р-79) |
| `avatar_of` | воплощение божества |
| `spawn_of` | порождение, потомство |
| `servitor_of` | служит божеству или существу (существа и персонажи) |
| `transforms_into` | может превращаться в другое существо |
| `relative_of` | родственник (взаимно) |
| `knows` | знакомый, друг, коллега (взаимно) |
| `rival_of` | недруг, соперник (взаимно) |
| `works_for` | работает на |
| `variant_of` | тот же преген в другом варианте |
| `related_to` | связан с: природа связи не ясна или спорна — книга сама сомневается или приводит другую версию (Р-83, Р-89); единственная или преобладающая версия («по преданию», «по мнению большинства») остаётся своим типом |

`note` — кем цель приходится этой записи, `note_back` — кем эта запись приходится
цели (показывается в карточке цели). `same_as` — та же запись в другой книге.
Способность может ссылаться на упомянутые записи (`abilities[].refs`).

## Статблок (общий для существ и персонажей, Р-01)

Характеристики `STR…EDU` (`raw`, `value`, бросок `roll` — остаётся на виду, Р-34),
`averages`; `hp`, `mp`, `damage_bonus`, `build`, `move` (режимы: ходьба, полёт,
плавание, рытьё…), `armor`, `attacks_per_round`; атаки (вид, навык, процент с
половиной и пятой, урон, ссылка `weapon` на справочник оружия, пояснение `notes`); `dodge`; навыки (`name`, ссылка
`skill` на справочник, `specialization`, значение); `spells` — строка `raw` как в
книге и `items`: названия заклинаний из неё по порядку со ссылкой `spell` на
справочник (Р-52; комментарии вроде «на усмотрение Хранителя» не разбираются); `sanity_loss`;
у персонажей — `luck`, `sanity`. Блок необязателен, если в книге его нет.

## Существо (`creature.schema.json`)

`name`, `aliases`, `category` (`animal | mythos_monster | mythos_deity | avatar |
supernatural`), `subcategory`, `axes`, `relations`, `statblock`, `abilities`
(«Способности»), `description`, `legend`, разделы Malleus (Р-28, Р-29): `aura`
(Аура), `encounters` (Встречи), `cult` (Культ), `blessings` (Возможные дары);
`habitat`, `sources`, `errata`, `corrections`, `quality`.

## Персонаж (`character.schema.json`)

Одна сущность (§3.2). `roles` (`npc`, `pregen`) — как персонаж подан в источнике,
подсказка, а не ограничение (Р-42). `stock_type` — «типаж» (слово «архетип» занято
Pulp Cthulhu, Р-26). `occupation` — профессия как в источнике, `occupation_ref` —
ссылка на справочник профессий (Р-46). `age`, `sex` (только если указан в тексте),
`residence`, `birthplace`, `player_chooses` (что выбирает игрок), `statblock`,
`abilities`, `background` — «Характер и окружение» (Р-44): описание, убеждения,
черты, значимые люди и места, ценности, травмы, фобии, тайные знания, встречи,
`secret` — тайна для Хранителя (Р-45); `possessions`, `wealth`, `legend`
(биография), `relations`, `same_as`. Поля «роль в сценарии» нет (Р-43): сценарий —
в `sources[].note`, роль — в легенде.

Групповой профиль (Р-74): `stock_type` и `variants` — несколько статблоков из таблицы книги
(«рядовой культист», 1–8); у существ поле `variants` то же. Статблок персонажа необязателен
(житель без характеристик, Р-78). Связь персонажа или именованного существа с видом,
статблок которого используется в игре, — `instance_of` (Р-79).

## Навык (`skill.schema.json`)

Справочник (Р-25): `name`, `aliases`, `base` (`raw`, `value`, `formula`: `half_dex`,
`edu`, `varies`), `category`, `uncommon`, `specializations` (своё базовое значение),
`description`, `examples`, `opposed_by` — контрнавыки (Р-47): чем противник отвечает
во встречной проверке (навык или характеристика `coc:characteristic:pow`, пояснение,
ссылка на страницу).

Навыки существ (Р-48, Р-49): навыки из статблоков, которых нет в правилах для
сыщиков, — записи категории `навыки существ` без базового значения (`base.raw` «—»).
Одна запись на английский термин книги (`name.en`: Scent Prey и т. п.); другие русские
переводы — в `aliases`. В статблоке существа остаётся напечатанное название, поле
`skill` ведёт на запись справочника, у групповых навыков — `specialization`.

## Заклинание (`spell.schema.json`)

Справочник (Р-51…Р-54): 193 заклинания веб-помощника и все, что упомянуты в картах.
`name` (ru — по русской «Книге хранителя», помощнику или наш перевод; en — оригинал,
по нему ссылаются карты, Р-33), `aliases` (альтернативные названия Grand Grimoire как
есть, русские варианты), `category` — тип (14, Р-66), `mechanic` — механика сотворения: мгновенное, поддерживаемое,
ритуал (Р-69…Р-72), `cost` (`raw` как в книге и разбор: `magic_points`,
`sanity`, `pow`, `other`), `casting_time`, `description` — что делает и механика полным
пересказом, `deeper_magic` — глубинная магия, `variant_of` — семейство («Связь с
божеством», «Вызов божества», «Заклинания призыва»…), `refs` — связанные существа
(карточка существа показывает «Заклинания о нём»), `sources`, `errata`, `corrections`,
`quality`. Числа: русская «Книга хранителя» > английская > Grand Grimoire > «Маски
Ньярлатхотепа» 7e (для их заклинаний) > помощник; расхождения книг — в `quality.notes`.

## Книга Мифов (`tome.schema.json`)

Справочник (Р-55…Р-57): книги главы 11 «Книги хранителя» (таблица XI) и книги «Масок
Ньярлатхотепа» 7e. Каждое издание — отдельная запись; `edition_of` ведёт на общую запись
книги (история, описание, список изданий — у «Некрономикона», «Книги Эйбона» и др.).
`name`, `aliases`, `tome_type` (`mythos_tome | occult_book`), `language`, `author`, `date`,
`description` (пересказ), `reading` (`sanity_loss`, `mythos_initial`, `mythos_full`,
`occult`, `mythos_rating`, `study_time`, строка `raw` как в книге), `spells` (название как
напечатано в списке книги + ссылка `spell`), `copies` — экземпляры из сценариев
(источник, страница, где лежит, свой список заклинаний со ссылками, Р-65), `refs` — существа и персонажи, о которых книга
(их карточки показывают «Книги о нём»), `sources`, `errata`, `corrections`, `quality`.
Числа — по русской «Книге хранителя»; данные конкретных экземпляров из «Масок» — в
`quality.notes`.

## Оружие (`weapon.schema.json`)

Справочник (Р-58, Р-59): 105 позиций таблицы XVII «Книги хранителя» (числа — по
изображениям страниц русского издания) и 57 моделей расширенного каталога 1920-х из
веб-помощника — пользовательский каталог, не книга (источник `weapons-catalog-1920s`,
флаг `editorial_text`). `name`, `aliases`, `group` (`melee | handgun | rifle | shotgun |
automatic | heavy | other`), `skill` (как в таблице + ссылка и специализация), `damage`
(`raw`, `dice`, `db`: full/half/none, `impaling`), `range`, `attacks`, `ammo`,
`malfunction`, `cost` (`1920s`, `modern`), `availability` (графа «Встречается»), эпохи в
`axes.era`, `description` с особыми правилами из сносок таблицы; у моделей — `model_of`
(позиция таблицы), `caliber`, `reload`. Атаки статблоков ссылаются на оружие
(`attacks[].weapon`, `pipeline/migrate/link_weapons.py`).

## Локация (`location.schema.json`)

Гайды по городам (Р-78, Р-80). `location_type` (`город | район | здание | место | область`),
`part_of` — где находится (здание → район → город; город верхнего уровня — `null`),
`number` — номер раздела по путеводителю/карте книги (101, 203…; районы — 100…1000), `address`
(почтовый адрес — другая система, чем номер раздела), `keeper_hint`, `description`, `history`,
`residents` (`id` персонажа или существа + `note`: кто живёт или бывает здесь; похороненные,
изображённые и упомянутые — не жители, а `refs`), `tables` (таблицы-вводные: `title`, `kind`
`слухи | встречи | события | зацепки | прочее`, `dice`, `intro`, `rows[{roll, text, refs}]`,
`source`), `refs`, `sources`, `errata`, `corrections`, `quality`.

Город — одна запись на все книги: каждая книга добавляет к нему свои места, таблицы и истории
со своим источником; гайд в просмотрщике — книга по `sources` мест. Просмотрщик: вкладка
«Гайды» (гайды, «Все гайды», режим «Дома / Жители», разделы справочника города; слева
город → район → место), у персонажа и существа — «Где живёт / бывает» и «Упоминается».

## Профессия (`occupation.schema.json`)

Справочник по главе 4 «Книги сыщика» (Р-46): `name`, `group` (общая профессия для
вариантов), `lovecraftian`, `description`, `skill_points` (формула как в книге и разбор,
варианты «ИЛИ»), `credit_rating` (Средства), `contacts`, `skills` (навык из
справочника, `count` для нескольких специализаций или `choice` — сколько и из чего).

# Схемы базы знаний

Черновик v0 для первого среза — существ (Р-14). Ждёт просмотра владельцем.

## Файлы

| Файл | Что это |
|---|---|
| `common.schema.json` | общие типы: текст, значение с исходной записью, источник, оси, флаги качества, общий шаблон статблока |
| `creature.schema.json` | существо (зверь, тварь Мифов, божество, воплощение, нежить) |
| `examples/creature/wolf.json` | простой зверь |
| `examples/creature/chthonian-adult.json` | раса Мифов: несколько атак, манёвр, умения, потеря рассудка по стадиям |
| `examples/creature/king-in-yellow.json` | воплощение божества с исправлениями данных веб-помощника |

Проверка примеров (без внешних библиотек):

```powershell
python tools\validate.py schemas\creature.schema.json schemas\examples\creature\*.json
```

## Как устроена запись

- **`id`** — стабильный идентификатор `coc:creature:<slug>`. По нему
  ссылаются другие записи и сценарии (`same_as`).
- **`name`** — `ru` обязательно, `en` если известно.
- **`category`** — `animal | mythos_monster | mythos_deity | avatar |
  supernatural`; `subcategory` — как в книге.
- **`axes`** — эпоха (`any`, `1920s`, …) и свод правил (`core`, `pulp`).
- **`statblock`** — общий для существ и персонажей (Р-01):
  - характеристики `STR…EDU`: значение, исходная запись `raw` и формула
    броска (`(2d6+6)×5`);
  - `hp`, `mp`, бонус к урону, комплекция, скорость с режимами (ходьба,
    полёт, рытьё…), броня;
  - атаки: вид (атака, манёвр, особое), навык, процент с половиной и пятой
    частью, урон (кубы, прибавляется ли БкУ, дополнительный эффект);
  - уклонение, навыки, заклинания;
  - потеря рассудка — список «успех/провал + когда».
- **`abilities`** — особые умения кратко.
- **`description`**, **`habitat`** — описание и где обитает.
- **`sources`** — книга, физическая и печатная страница, способ получения,
  сверено ли с книгой.
- **`corrections`** — что исправлено относительно данных веб-помощника и
  почему.
- **`quality`** — флаги: `ocr_suspect`, `parse_uncertain`, `incomplete`,
  `editorial_text`.

Принцип: рядом с каждым разобранным числом лежит запись как в книге (`raw`).
Если разбор ошибся, исходник остаётся доказательством.

## Что показали примеры

- **Хтониец:** в данных веб-помощника пропущен манёвр «Захват и высасывание»
  (урон 2d6 + высасывание крови). В примере он восстановлен и помечен
  `parse_uncertain`: процент манёвра в книге отдельно не указан.
- **Король в жёлтом:** восстановлены обрезанный урон и потеря рассудка
  (0/0 в маске, 1d3/1d10 без маски). Исправления записаны в `corrections`.
- **Физическая и печатная страница** в главе 14 различаются на 21 (стр. 299
  PDF = стр. 320 книги), поэтому хранятся обе.
